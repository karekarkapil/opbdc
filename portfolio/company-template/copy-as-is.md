# Copy as is

*Companion to Chapter 16, "The Second Company", of* 1 Person, Billion Dollar Conglomerate *(2026 edition). Last reviewed: September 2026.*

## What this is

The list of everything from your first company that carries across almost unchanged. "Almost" matters: the method copies, but every account, key and permission is created fresh for the new company. **Copy the know-how, never the access.**

## How to use it

Work down the table. For each row, copy the file from your first company's folder (or from this repository if you never customized it) into the new company's folder, change only what the last column says, and tick it.

## Before any agent starts work

- [ ] Every account in the new company's name, not company one's and not yours personally.
- [ ] Every agent has its own new identity and keys for the new company.
- [ ] No file copied from company one contains a customer name, price, policy or credential from company one. Search for company one's name, domain and product names in the new folder; the count must be zero.
